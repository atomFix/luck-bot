# Companion 本地管理后台、对话记录与用量账本

日期：2026-10-24（Asia/Shanghai）
状态：新增后台范围的书面设计，待用户审阅；尚未创建数据库、持久化对话或更改凭证显示功能。

## 目标与范围

用户已确认声纹方案，并要求把后台升级为管理系统：每轮对话、回应、花费、响应耗时、token消耗均可追查；配置凭证可以查看；先使用本地SQLite，以后可迁移云数据库。

已确认的声纹交互继续执行：本地匹配已录入的人后自动理解、只回应表情；唤醒词进入有声聊天。该设计见 `2026-10-24-speaker-aware-expressions-design.md`。本文件是独立后台子项目的设计，先建立账本和诊断基础，再接入新声纹/背景表情功能；两者分别编写实施计划，避免把模型可行性和管理后台绑成无法独立验收的一次升级。

本次用户明确要求持久化对话文本，更新此前仅内存保留的默认。只持久化被接受轮次的识别文字与回答文字；不保存原始麦克风录音。声纹向量依旧独立加密保存，不进入对话详情、账单或导出记录。陌生人/不确定片段没有ASR文本，只记录拒绝原因、数值耗时和零云调用。

## 路线选择

| 方案 | 取舍 | 决定 |
| --- | --- | --- |
| 扩展已有本机后台＋SQLite | 复用配对、Keychain、会话鉴权、安装包与常驻进程，不需要另开服务 | 采用 |
| 独立Python/Rust管理服务 | 便于单独部署，但增加进程、端口、配置与打包，重复现有能力 | 当前不采用 |
| 现在接云数据库 | 可远程共享，但增加账号、网络和部署依赖 | 仅保留迁移边界 |

保留现有TypeScript/Swift与原生网页，按页面拆分脚本和样式，不为后台另引入前端构建框架。本机Node固定22.22.3，数据库采用该运行时的`node:sqlite`；SQLite连接放入独立worker，使用异步Repository接口与音频编排解耦。真实兼容性在实现首项验证，未验证前不声称现有包已支持SQLite。

## 页面与交互

页面使用左侧导航＋主内容区。现有设备、配对、开关和手动控制迁入对应页面，所有功能仍从已安装应用打开的本机后台访问。

### 1. 概览

显示设备在线/模式/后台聆听状态、今日轮次及成功/失败/取消/忽略数量、今日已知用量及费用、未知费用请求数和各阶段响应统计。展示统计时间范围、样本数和数据来源；没有数据时显示“暂无记录”，不能把缺失延迟显示为0ms。

最新轮次表可以进入详情。云端实际计费金额与按配置估算的金额分栏，不拼成一个“实际总花费”。有未知请求时标注已知小计，不能冒充完整总额。币种分开汇总。

### 2. 对话记录

列表列：时间、设备、模式（唤醒聊天/后台表情/文字测试）、识别的人（可为空）、用户文字摘要、表情、状态、总耗时、token、已知费用/估算/未知标记。

支持时间范围、设备、模式、状态、声纹档案筛选及关键词查询，分页读取，每页25条，可切50/100条。正文作为纯文本呈现，模型输出不能成为可执行HTML。没有声纹或被删除的人显示对应历史占位，不把一个旧档案ID错误映射到新的人。

详情由三部分组成：

- 对话与回应：完整识别文本、最终或部分回答、最终表情/保持时长、真实设备确认、声音是否尝试/已观察播放/已排空、结束或失败原因。
- 时间线：采集、VAD/声纹、ASR、语义、设备应用确认、回复首token、TTS首PCM、Mac首缓冲区播放回调、排空、结束；缺失阶段显示未发生或未知。
- 请求明细：每次HTTP尝试或TTS任务的供应商、配置快照、模型、状态、耗时、usage和费用来源，包括取消前已发出的请求。

纯表情轮次明确显示“无需聊天回答／TTS”，不会用空白回答暗示失败；唤醒失败、识别空文本、取消、中途断线等也有记录。历史数据从功能启用后开始，不能重建之前未保存的谈话。

### 3. 用量与费用

按日、供应商、模型和模式汇总，查看请求次数、成功/失败/未知、输入/输出/cache token、ASR音频时长、TTS字符/供应商计量、费用和未完整计量数。

价格配置支持供应商＋模型＋计费项、币种、单位、单价、生效时间和来源备注。初始未核验的价格留空，不猜测套餐、折扣或用户账户实际价格。每条请求保存当时价格快照，修改价格不会静默改写旧记录。未提供计费依据的数据保持未知。

明确区分：

1. `provider_reported`：供应商返回的实际计费金额，有币种与原始金额来源；只有真的返回才能使用这个标签。
2. `estimated`：用实际或测量用量乘以当时价格快照，界面标“估算”；实际token数并不代表实际账单金额。
3. `unknown`：usage、价格、币种或计费规则不足，金额为NULL；失败、超时、取消也可能计费，不能归零。
4. `not_applicable`：本地阶段或没有发起的请求，不属于云端费用。

未知与0是不同含义。缓存命中/未命中是输入token的分项，不重复叠加到总输入。供应商未给缓存细分且价格依赖细分时，不虚构分布。按秒/字符计费的ASR/TTS不强行换算成token；供应商未返回的token为NULL。

### 4. 声纹与聆听

承接已确认设计的档案录入、启用、删除及质量结果，后台表情开关、默认20秒开口等待、句尾静音与状态提示。后台管理先落地时，此页可显示能力尚未实现及现有等待设置，不提供虚假的成功录入按钮；后续声纹子项目启用真实流程。

### 5. 服务配置与凭证

展示DeepSeek模型、ASR/TTS服务商/地址/模型/音色、Mac/开发板输出、设备配对和连接状态，保留现有DashScope预留接口的真实能力标记。

用户要求能查看已配置凭证：每行提供小眼睛，可显示当前Keychain中的完整值、再次遮住、编辑保存和删除。默认遮住，显式查看时才读取真实值；切页、失焦或30秒后清除明文展示，不自动复制到剪贴板。不能只显示空输入框让用户误以为可以查看却看不到现有值。

凭证仍存Keychain；SQLite与JSON设置只保存引用及配置变更元数据。明文查看使用独立的本机UI POST接口、现有会话＋CSRF＋Host/Origin校验和`no-store`，不通过定时`state`响应、通用CLI/MCP动作或日志返回。可以记录“查看/变更了哪个服务商配置”的事件，但不记录值、请求体或响应体。

## 数据模型与迁移边界

本地路径：`~/Library/Application Support/Round Eyes Companion/companion.sqlite3`，目录0700、数据库及WAL/SHM仅当前用户可读写。SQLite开启foreign_keys与WAL，使用有界写入队列、参数化SQL和事务；不是每20ms音频帧写库。

| 表 | 职责与关键字段 |
| --- | --- |
| `schema_migrations` | schema版本、迁移ID、应用时间；启动事务迁移，不支持的未来版本拒绝写入 |
| `sessions` | 应用会话UUID、设备ID、boot/session ID、开始/结束时间、模式 |
| `turns` | 轮次UUID、session、设备turn_seq、source/mode、speaker档案引用/名称快照、状态、文字/部分回答、表情、时长、时间与安全错误码 |
| `turn_spans` | 轮次/阶段/请求UUID、开始和耗时、是否完成、观察来源；阶段可出现多次 |
| `provider_attempts` | 逻辑请求UUID＋尝试UUID、轮次、ASR/reaction/reply/TTS、供应商、请求模型/实际模型、开始/结束/状态、供应商request ID、安全错误码 |
| `usage_items` | 尝试UUID、计量名称/单位/值、来源（供应商/本机测量）、是否完整；NULL表示未知 |
| `price_versions` | 供应商、模型、计费项、币种、计费单位、十进制单价、生效期、来源 |
| `cost_items` | 尝试UUID、费用类型、币种、十进制金额、计量/价格快照、完整性 |
| `admin_events` | 应用启动/停止、配置/凭证变更与显示、记录删除/持久化故障等元数据，无秘密值 |

应用层使用UUID和UTC毫秒时间、枚举与明确nullable字段，不使用SQLite rowid作为跨系统标识；金额以规范十进制字符串存储并采用十进制定点运算，禁止JS二进制浮点直接累计钱数。

Repository使用异步接口，屏蔽SQL、事务和分页实现。业务层发出结构化轮次/请求事件，不直接依赖SQLite；以后增加PostgreSQL/MySQL等实现与导入工具，不承诺无需schema适配即可把SQLite文件搬到云端。第一版不实现云同步、远程后台或公网端口。

现有`settings.json`保留运行配置，Keychain保留秘密值，声纹库独立加密；本次不为“全放数据库”迁移已验证配对。SQLite中保存用于解释历史行为的非秘密配置快照及凭证引用。备份/导出只在用户操作时进行，不自动推送Git或云端。

## 全链路记录和计时合同

- 接受采集/文字动作时先分配轮次UUID。设备turn_seq可能在新会话归零，不能单独当全局主键。boot/session与应用进程代次保留用于定位重连。
- 每轮终态为completed/ignored/failed/cancelled/interrupted；应用恢复后将遗留running轮次和pending请求标为interrupted/usage_unknown，不能永远显示运行中。
- 文字/表情/播放结果分别记录，部分回答在取消时仍可查看；模型返回表情不等于板端已显示，需保留实际applied ACK。
- HTTP每次重试和每个TTS句子任务单独建attempt。写入开始记录后再发送网络请求；网络已发出但用量未回时保留unknown，不用一次逻辑调用掩盖两次潜在计费。
- DeepSeek非流式读取response usage；流式请求在服务支持时申请末尾usage并解析不含文本的usage chunk。提前取消或服务不支持则标记不完整，不能按字数猜token。
- MiniMax ASR/TTS保留当前适配器，增加结构化usage和请求元数据提取；只有已核验字段才能记为供应商计量。本机采集样本数、合成输入字符数和PCM长度是独立的measured值，不冒充供应商计费单位。
- 日期/筛选用UTC时间戳并按本地时区显示；阶段耗时使用同进程单调时钟，不能用可能跳变的系统时间相减。跨重启的缺失阶段不编造耗时。
- 总耗时包含明确口径：采集开始→终态，以及句尾检测完成→表情ACK/首音频分别统计。并发/重叠阶段不简单相加作总耗时。
- 播放时间继续注明是首个`dataPlayedBack`软件观察，不冒充外部声学测量。
- 分页/筛选/统计全部来自数据库，不能只显示内存最近60条；统计口径含样本数、未知项和币种。

## 保留、失败与删除

默认自启用后持续保存文字与账本，直到用户在后台清理；提供暂停保存正文选项，开启后仅记元数据及用量，历史正文不会自行删除。该开关与现有语音历史清空按钮含义分开：清空模型上下文不等于删除持久化记录。

支持按时间清理会话正文或完整记录，并明确影响统计；操作前展示范围/数量并确认。SQLite删除不宣传为磁盘安全擦除，保留的备份也需单独管理。诊断日志和Git不保存正文或密钥。

数据库不可写、磁盘满、迁移失败或worker退出时，UI明确显示“记录不完整／存储故障”，暂停发起新的云端处理，以免形成看似完整但静默漏账的运行；当前音频/VAD与本地专注状态仍可安全停止，用户可关闭服务修复。网络请求开始记录持久化失败则不发送；请求已发出而最终usage写入失败，重启后保留该pending事实并显示未知。队列溢出不能无限缓存正文。

对话文本只通过受保护的本机UI读取；现有MCP/CLI控制功能不默认获得历史谈话或凭证读取权。后续云数据库部署的账号、权限、TLS和同步策略单独设计，不因本次本机实现默认开放。

## 验证和交付

- SQLite真实临时文件迁移、重开、外键、分页/筛选/聚合、重复事件幂等、异常中断恢复和金额精度验证；内存fixture不能代替持久化测试。
- provider fixture覆盖流式末尾usage、无usage、取消、失败、重试、缓存token及多段TTS，验证请求数/用量/费用不漏记或重复。
- 管理UI验证长正文、中文、模型输出HTML、空状态、筛选分页、未知费用、混合币种和数据库故障；使用真实安装目录与浏览器完成页面检查。
- 凭证sentinel测试证明小眼睛可显示已存值，同时普通state、SQLite、审计/诊断、导出和MCP/CLI不含该值；错误Origin/CSRF请求不能读取。
- 真实有声聊天与纯表情分别验收记录对应关系；不得用synthetic/fixture账单冒充实际消费。默认不为“补账”增加付费调用，不回填历史不存在的谈话。
- 复测安装包内SQLite worker、签名、清单、Keychain helper字节稳定、升级保留配对和数据库迁移/回滚。数据库迁移前创建私有备份；旧应用不支持新schema时使用匹配备份，不让旧版直接写新库。
- 实施后单独报告管理页面/数据库/用量核验与声纹/固件实机验收，未完成的阶段明确pending。

本设计确认后先编写后台实施计划，再与已批准的声纹子项目计划衔接，在当前聊天中继续开发；暂不创建外部服务。
