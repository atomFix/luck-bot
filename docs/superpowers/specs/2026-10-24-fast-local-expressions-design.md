# Fast local semantic expressions

User approved local streaming recognition + fast expression classification + DeepSeek for complex semantics and asked to execute. Goal: reduce stop-speaking-to-visible-expression latency without weakening speaker gate. Baseline7 successful ambient turns: speaker48ms median, MiniMax ASR922ms, DeepSeek726ms, ACK24ms, plus1000ms silence.

Keep existing Companion/board protocol and installed25poses. Local ASR worker reuses pinned sherpa2.0.0 CPU1 thread, official small Chinese streaming Zipformer CTC int8 model. Model/native licenses, byte counts and hashes verified; original speech profiles retained as explicit cloud fallback. No firmware flash required. Background streaming begins at sustained VAD onset with500ms pre-roll; feed only bounded in-memory PCM, finish at600ms quiet by default. ASR runs locally before speaker match, but its text is discarded for unmatched/short/cancelled inputs. No automatic cloud fallback after local ASR failure: visible failure/status, cloud mode remains selectable.

Conservative deterministic local classification matches only explicit first-person simple emotional statements/greetings. Negation, contrasts, multiple emotions, hypotheticals, quotes, questions, instructions, sarcasm indicators, third-person stories, contextual references and uncertain text defer to DeepSeek. All local emotions use approved enum/2500ms hold; no reply/TTS for ambient. Complex cloud reaction receives only final matched transcript and existing bounded history. Voice chat still creates replies/TTS, may consume local ASR in whole-utterance mode.

Existing audio service handles single active+single pending semantic candidate. Local ASR handles at most2 streams (current capture+previous finalizing), PCM max960k/stream, main worker queue bounded; no cloud requests for unknown. Worker load errors/timeouts crash closed; cancel/pause/reconnect/enroll/manual/voice reset streams and reject pending. Quiet gates still ensure listening priority and defer semantic display until quiet. Ledger records local ASR/finalization/local reaction spans and route codes, cloud attempts only when actually called; no invented token/cost for local work. UI explicitly selects local vs configured cloud ASR and fast path, model readiness/error visible; original profile configs/keys and speaker vault preserved.

Only latest local partial text stays in memory, never drives an emotional prediction before full text/speaker verification. Target <1s stop-to-visible for straightforward sentences, measured on real Mac/board; not a guaranteed acceptance number before benchmarking. Official test WAV validates local Chinese decoding and chunk processing; synthetic tone/silence only proves load. Preserve source vs package vs real user acceptance distinctions.
